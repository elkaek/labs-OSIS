## 2. Проверка сети, обновление системы и доустановка GUI (MATE) (+ Настройка сети и проверка обновления системы)

В процессе установки через сетевой установщик (`netinst`) была выбрана минимальная конфигурация (только SSH-сервер и базовые системные утилиты, без графической оболочки)

Сразу после первого входа в консоль чистой системы была выполнена проверка работы сетевого адаптера (NAT) и DNS-резолвинга с помощью утилиты `ping`:


## 3. Настройка SSH-доступа и удаленное подключение

Служба безопасной оболочки (`SSH`) была выбрана и инсталлирована ещё на этапе первичной установки системы. Для организации удаленного доступа с основной (хостовой) машины под управлением Windows потребовалось проверить её статус и настроить сетевой проброс.

### Шаг 1. Определение IP-адреса ВМ и перезапуск службы SSH

Внутри виртуальной машины в терминале MATE был определен локальный IP-адрес сетевого интерфейса `enp0s3` с помощью команды `ip a` (получен адрес `10.0.2.15`), а также выполнен перезапуск службы SSH:

```bash
# Проверка сетевых интерфейсов
ip a

# Перезапуск службы SSH для применения настроек
systemctl restart ssh
```

### Шаг 2. Настройка проброса портов (Port Forwarding)
Так как сетевой адаптер ВМ работает в режиме NAT, для доступа к ней с хостовой системы в настройках VirtualBox было создано правило проброса портов:
* **Протокол:** TCP
* **IP хоста / Порт хоста:** `127.0.0.1` / `2222`
* **IP гостя / Порт гостя:** `10.0.2.15` / `22`

```cmd
ssh el@127.0.0.1 -p 2222
```

### Вывод
В ходе лабораторной работы установлен гипервизор Oracle VirtualBox (с пакетом расширений Extension Pack), создана виртуальная машина с выделением 4 ГБ ОЗУ, 2 ЦПУ и диска объёмом ~30 ГБ. На гостевую систему установлена ОС Debian 13 (amd64, netinst) с именем хоста debian и пользователем el. Из-за особенностей минимальной установки (без графического окружения) через системную консоль были успешно доустановлены и настроены оконная среда MATE и дисплейный менеджер LightDM. Проверено сетевое подключение в режиме NAT (выполнена успешная проверка связи через ping до внешних ресурсов и обновление индексов пакетов с помощью apt update && apt upgrade). Настроен и активирован SSH-сервер (openssh-server), а также организован удаленный доступ с хост-машины (Windows) через проброс портов (порт хоста 2222 - порт гостя 22) с успешной авторизацией по паролю. Цель работы достигнута: освоены технологии виртуализации, ручная доустановка компонентов в Linux, настройка сети и организация удалённого администрирования.
